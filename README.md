# Mirror Abyss / 镜渊

版本：`3.0.0-lite.ui.19-mobile-layout`

Mirror Abyss 是 SillyTavern 的长期游玩记忆扩展。世界书是唯一长期事实源：模型负责理解和整理语义，插件只负责请求、协议、UID、事务、回滚与界面，SillyTavern 负责世界书记录和调取。

## 单一处理链

```text
每回合正文 → 事实提取 → 场景批次 → 小总结 → 多场景批次 → 大总结
```

- 提取只记录已明确发生、会影响后续运行的重要事实和连续性锚点。
- 小总结只压缩当前场景批次的世界书条目，形成中颗粒条目。
- 大总结只压缩多个小总结结果，形成长期颗粒条目。
- 总结不得生成下一步行动、调查目标、剧情方向、任务或未来规划。

## 提取协议

```text
事实｜类型｜稳定名称｜栏目｜建立/变化/结束｜关联对象｜完整事实
```

类型为人物、场景、物品、事件或世界。基础栏目如下；模型可以明确给出结构合法、含义不重复的扩展栏目。

| 类型 | 基础栏目 |
|---|---|
| 人物 | 身份、经历、当前状态 |
| 场景 | 位置、状态、场景阶段 |
| 物品 | 来源、状态、所属关系 |
| 事件 | 事件过程、事件结果、影响 |
| 世界 | 世界规则、环境状态、长期变化 |

人物基础栏目不包含“关系”。协议中的“关联对象”仍用于记录本条事实明确关联的对象。

模型不读取、生成、选择或返回 UID。插件只按输出中的“类型＋稳定名称”做精确唯一匹配，并在内部取回已有 UID；重复身份会拒绝自动写入。标题由代码机械生成为 `类型｜稳定名称`，基础关键词机械复制稳定名称。

## UID 与写入安全

- UID 是唯一写入身份；标题、别名和相似文本不能替代 UID。
- 更新保留 UID。
- 合并产生新 UID，来源 UID 标记为沉降，不直接删除事实。
- 全部自动写入经过协议校验、UID定位、写入计划、快照检查、提交和权威回读。
- Edit、Swipe、Delete 或聊天切换会使旧任务失效；已提交影响依赖回执和 UID 快照恢复。撤回窗口固定保留最近 20 个已处理回合，避免无限增长。
- 基石锁只限制自动写入，不改变事实内容。

## 场景与总结触发

场景标记是运行辅助数据，不是世界事实。场景边界只比较结构化场景名称的最大包含层：`主场景/子地点` 中主场景相同表示同一场景，主场景名称变化才表示换场。系统不使用字符串相似度推断场景。

SL 只累计当前场景实际写入的提取量，用于小总结触发；大总结依据已经完成的小总结或场景组数量触发，不使用 SL 判断剧情意义。

## Prompt 与错误边界

- 每项功能只有一个有效 Prompt。
- 提取输入为轻量世界书索引及相关栏目、玩家本轮回复和当前 AI 正文。
- 自动提取默认开启，玩家可在维护页明确关闭。
- 超时和 502/503/504 等瞬时请求错误只做有限重试；401、取消和协议错误分别处理。
- 固定协议错误时，第二次请求保留原任务和输入，并附上错误原因与错误输出，只要求修正格式。
- JSON 兼容只转换结构，不补事实、不推断缺失字段。
- 敏感内容预处理只作用于发送给提取模型的副本，不修改聊天或世界书。
- 权限错误、玩家取消和协议错误分别处理，不混作普通网络重试。

## 界面

- 主聊天正文下方：最新回合显示紧凑完整状态条，历史回合收缩为小标记，点击进入运行页。
- 运行：保留完整处理、审核、提取、取消任务、小总结、大总结与失败重试。
- 手记：白底黑字的紧凑游戏档案，条目按固定类型图标展示；条目、文件夹、移动、总结、合并和删除均在手记修改模式内。
- 维护：世界设定导入、状态概览、Provider、模型、世界书绑定、诊断、导出与恢复。世界设定可直接粘贴文本或读取 TXT，两者共用“AI 整理 → 预览 → 确认写入”链路。

手记支持玩家自建一级文件夹、重命名、删除、折叠、文件夹排序、条目拖入文件夹和同文件夹排序。桌面端可拖拽；窄屏可使用分类下拉与上下移动按钮。新条目默认进入“默认分类”。文件夹、排序、折叠和召回标签属于 UI 编排，不是事实来源，也不能改变条目正文或 UID。

## 安装

将 deploy 包内容放入 SillyTavern 扩展目录。运行文件为：

- `index.js`
- `app.js`
- `manifest.json`
- `README.md`
- `LICENSE`

`index.js`、`app.js`、`manifest.json` 与本 README 的版本号及动态加载缓存键必须一致。
