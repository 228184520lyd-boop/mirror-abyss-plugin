# Mirror Abyss 2.0.0-lite.ui.2

面向 SillyTavern 1.18 的轻量操作版。

## UI

- 右上角“镜渊”入口固定在官方顶部按钮区下方的边缘位置，不插入角色卡按钮容器。
- 面板只保留“审核”“提取”两个按钮。
- 总开关、自动审核与提取、审核开关、提取开关相互独立。
- 最新 AI 正文下方显示可读状态灯，包括处理阶段、条目标题和写入结果。

## 审核

点击“审核”读取最新一轮玩家输入与 AI 正文。通过时不修改；不通过时生成完整修正版并替换最新 AI 正文。

## 提取

点击“提取”后：

1. 一次模型调用输出人物、地点、物品、事件、关系五类固定格式条目。
2. 内置正则/结构解析器拆分标题、关键词和事实小标题，不依赖 SillyTavern Regex 扩展。
3. 标题写入世界书 comment，关键词写入 key，事实正文写入 content。
4. 已有条目按状态槽替换、经历链追加、关键词与关联条目集合合并。
5. 本地二元组语义相似度用于去除近义重复，不增加第二次模型调用。

## 默认行为

- 默认手动模式，不自动处理新消息。
- 默认使用当前连接。
- 当前聊天必须已绑定世界书。
- UI 只映射功能；审核、修正、提取、解析、合并与写入均由代码层执行。


## lite.ui.2 修正

- 入口移到官方顶部按钮区下方的右上角边缘，不再插入 `top-settings-holder`，避免挤压或遮挡角色卡按钮。
- 新增“自动审核与提取”独立开关，并同时监听 `MESSAGE_RECEIVED` 与 `CHARACTER_MESSAGE_RENDERED`。
- 正文状态灯显示审核/提取的实时阶段、提取到的条目标题，以及新建、更新、跳过数量。
- 提取模型必须输出严格 `ENTRY/KEYWORDS/CONTENT/END_ENTRY` 语法；标记、小标题顺序、名称或关键词不合格时拒绝写入。
- 事件过程与关系变化分别归属事件/关系条目，其他条目仅引用，降低跨条目重复。
