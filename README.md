# Mirror Abyss｜镜渊 2.0.0-alpha.9-infopoint.8-player-simple

本候选继续使用“信息点提取 → 候选匹配 → 世界书操作”的内核，世界书仍是唯一剧情数据源，UI 只做读取、筛选、编辑和回读映射。

## 玩家界面减法

玩家可填写的内容现在只保留：

- 审核规则；
- 提取补充要求；
- 关键词名称；
- 关键词近义词；
- 关键词提取范围；
- 建议小标题；
- 可选的指定世界书名称；
- 小总结与大总结频率。

以下参数不再显示为玩家输入项：

- 响应 Token 与超时；
- 普通事实和事件链重复阈值；
- 正文相似度阈值；
- 常驻、向量、递归；
- 深度、顺序；
- 小标题内部写入策略；
- 通用调度规则。

这些全部使用插件默认值或由关键词、焦点和当前正文自动判断。

## 默认内容

首次加载或旧设置为空时，审核规则和提取补充要求会填入可直接使用的默认文本。默认关键词、小标题和事件状态选项也会自动补齐；玩家自定义关键词仍保留。

“匹配”页不再提供空白的 AI 原始填写框。没有运行记录时显示只读格式示例；运行后显示最近模型结果和匹配操作。

## UI 修复

- 右上角刷新与关闭改为内嵌 SVG，不依赖宿主图标字体；
- 关键词卡只显示玩家需要的四类文本和启用开关；
- 基础设定常驻、向量、深度和顺序不再显示；
- 设置页只留下世界书选择和总结频率；
- 手机端继续使用单列卡片布局。

## World Info 适配

不再硬编码加载 `/scripts/world-info.js`。插件优先使用 SillyTavern `getContext()` 已提供的 `loadWorldInfo`、`saveWorldInfo`、`updateWorldInfoList` 和 `reloadWorldInfoEditor`；宿主缺失这些方法时，才使用同源 World Info HTTP 端点作为后备。
