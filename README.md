# Mirror Abyss｜最终审计候选

这是针对真实云端诊断报告制作的候选包，不是新的功能版本。

## 安装

将安装包中的文件覆盖到现有 Mirror Abyss 扩展目录，然后完全刷新 SillyTavern 页面。

## 首次复测

1. 保持当前测试聊天和世界书。
2. 在 ST 中确认普通聊天可以正常生成。
3. 打开镜渊，运行一次“全自动实机验收”。
4. 导出诊断 JSON。
5. 正常发送两轮剧情，检查世界书是否产生真实新增或更新。

诊断已改为一轮真实宿主闭环，避免旧工具连续三轮重复调用同一模型。

## 独立 Profile

上一份报告没有配置任何 Connection Profile，因此只验证了当前主连接。需要验证独立处理模型时，请先在 ST 中建立 Connection Profile，再将“提取”阶段指向该 Profile。
