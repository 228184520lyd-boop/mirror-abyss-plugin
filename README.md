# Mirror Abyss 2.0.0-lite.ui.6

面向 SillyTavern 1.18 的轻量审核、事实提取、总结沉降与世界书召回调度扩展。

本版继续保持轻量结构。只吸收参考包中已经验证过的条目合并、总结分发和召回字段规则，没有移植其大型 Runtime、Outbox、迁移协调器或工作区架构。

## UI

- 右上侧独立入口，不进入角色卡按钮容器。
- 面板仅保留两个执行按钮：`审核`、`提取`。
- 独立开关：总开关、自动审核、自动提取、自动小总结、自动大总结、审核功能、提取功能。
- 可设置小总结轮数、大总结计数和队列压缩阈值。
- 最新 AI 正文下方显示审核与提取状态：关闭、排队、处理中、完成、失败，以及本轮条目标题、新建、更新、合并、修复和跳过数量。

## 严格顺序异步队列

自动流程固定为：

1. AI 正文完成。
2. 自动审核开启时，先审核并等待修正版替换、保存和回读完成。
3. 自动提取开启时，再提取审核后的最终正文；自动审核关闭时直接提取原正文，不发送审核请求。
4. 达到总结阈值后执行小总结或大总结。

手动按钮和自动任务进入同一聊天的后台异步队列。同一聊天严格串行，避免正文替换、提取和世界书写入互相覆盖。

队列积压达到阈值时：

- 已经排队的审核仍保留；
- 尚未开始的逐轮提取被压缩；
- 用一次小总结或大总结承接积压范围；
- 过期提取任务标记为已替代，不再逐项执行。

## 提取容错与部分提交

模型仍被要求输出严格的：

```text
<<<ENTRY:类型:稳定名称>>>
<<<KEYWORDS>>>
- 稳定名称
- 关键词
<<<CONTENT>>>
固定小标题正文
<<<END_ENTRY>>>
```

允许类型：人物、地点、场景、物品、事件、关系。

解析后手：

- 清理代码围栏、解释文字、全角标记和重复控制标记；
- 能确定边界时补齐缺失的关键词或结束标记；
- 同标题重复条目本地合并；
- 当前状态同槽后值覆盖前值；
- 经历、变化与事件进程去重追加；
- 跨条目重复事实按直接归属保留一份；
- 有效条目正常提交，异常片段单独隔离，不因一个错误条目拒绝整批；
- 本地无法得到任何安全条目时，只进行一次格式修复模型调用；仍失败则零写入并显示跳过原因。

## 宽场景卡

`场景`与跨场景长期存在的`地点`分开。场景卡固定覆盖：

- 场景范围；
- 稳定空间；
- 环境状态；
- 在场对象；
- 可交互资源；
- 空间限制；
- 当前功能；
- 局部变化；
- 关联条目与别名。

场景不会再被压缩成一句地点状态。

## 小总结、大总结与分发

小总结：

- 压缩近期场景、人物、目标、冲突、结果和未解决事项；
- 通过固定的`类型｜稳定名称｜小标题｜事实句`格式把事实分发回人物、地点、场景、物品、事件和关系条目；
- 生成或更新`总结｜当前事件`。

大总结：

- 沉降长期关系、永久变化、重大结果、世界规则和长期目标；
- 把长期事实分发回对应对象；
- 生成或更新`总结｜世界历史`；
- 分发成功后消费未锁定、非焦点的`总结｜当前事件`容器。

## 受限递归与召回重排

普通条目默认禁止递归传播。每次总结后确定性重排 SillyTavern 世界书字段：

- `constant`
- `vectorized`
- `preventRecursion`
- `excludeRecursion`
- `delayUntilRecursion`
- `depth`
- `order`
- `position`
- `scanDepth`

最多只有两类当前连续性条目可作为递归桥：

- 最新的`场景`或旧版`时空`条目，两者只取更新较新的一条；
- 当前仍在进行的事件。

基础设定常驻且隔离；小总结为终端近期记忆；大总结为终端历史向量；普通、近期和长期对象均可向量召回但不向外递归；历史对象同时禁止被递归链继续传播。

## 实机边界

本地测试覆盖语法、队列、正文替换、提取容错、总结分发和召回字段。真实模型是否严格遵循提示词、云端世界书权限以及具体 SillyTavern 部署差异，仍需在目标实例中实测。
