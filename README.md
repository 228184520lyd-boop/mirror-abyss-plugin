# Mirror Abyss / 镜渊

Mirror Abyss 是面向 SillyTavern 的长期剧情记忆管理扩展。它以 **SillyTavern World Info / 世界书作为唯一长期事实源**，负责把聊天中已经发生的变化整理进世界书，并在长期游玩中逐层总结、合并与提炼。

当前版本：**4.0.126**  
最低 SillyTavern：**1.18.0**

## 运行原理

```text
AI 回复完成
→ 可选：终稿处理
→ 提取本轮已经发生的重要变化
→ 写入当前世界书
→ 新的「场景」条目出现时，关闭上一 SceneGroup
→ 小总结：根据该场景材料进行总结、合并与提炼
→ 累计若干小总结
→ 大总结：根据这些材料进行更高层级的总结、合并与提炼
→ SillyTavern 原生 World Info 负责后续召回
```

插件不维护第二套剧情数据库，也不自行判断剧情事实。语义理解、提取、总结和提炼交给模型；插件只负责 UID、格式、任务生命周期、世界书读写与 UI。

## 使用要求

- 使用能够稳定遵守镜渊输出格式的模型与连接。
- 世界书是唯一事实源；不建议让多个自动记忆扩展同时修改同一本世界书。
- `场景` 是自动小总结的生命周期锚点：首次进入或真正切换场景时，提取结果需要产生正常的 `[场景][名称][关键词][栏目][事实]` 条目；同一连续场景应保持稳定名称。
- 模型连接、上下文长度与网关稳定性会直接影响提取、总结和整本整理。
- 大规模整本整理会按 SillyTavern token 计数自动分批；单条异常巨大的世界书条目仍可能需要先人工整理。

## 主要功能

- **提取**：记录本轮已经发生的重要变化。
- **小总结**：根据一个已结束场景的材料进行总结、合并与提炼。
- **大总结**：根据多个已完成场景的材料进行更高层级的总结、合并与提炼。
- **终稿处理**：使用玩家填写的唯一要求，对当前 AI 正文执行一次最终处理。
- **历史恢复**：Edit / Swipe / Delete 后，按当前 SillyTavern `world_info_depth` 有限重建受影响范围。
- **整理整本世界书**：逐条整理现有世界书；先生成内存预览，玩家确认后才写入。

## 最短使用方式

1. 在 SillyTavern 中安装扩展并打开一个聊天。
2. 选择当前连接或 Connection Manager Profile，并执行一次 API 测试。
3. 开启需要的自动提取、小总结、大总结与终稿处理。
4. 正常游玩。镜渊写入世界书，SillyTavern 原生 World Info 负责召回。
