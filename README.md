# Mirror Abyss 2.0.0-lite.ui.52-full-matrix

Mirror Abyss（镜渊）是 SillyTavern 前端扩展，用于在正文生成后执行可选审核、完整修正、事实提取、分层总结、世界书事务提交和 ST 原生召回配置。

本版本完成全插件矩阵审计，重点修复任务路由快照、Profile UI 映射和胶水代码冗余。世界书正文及栏目格式保持不变。

## 固定边界

- 世界书是唯一长期剧情数据源。
- 插件负责读取、转换、校验和提交，不建立第二剧情数据库。
- 模型只返回候选协议；匹配、合并、生命周期、原生字段、事务提交与回滚由插件确定性执行。
- API、地址、密钥、模型、Preset、Instruct、推理模板和供应商响应解析由 SillyTavern 管理。
- 镜渊不直接请求外部模型接口，不实现供应商兼容层。
- 玩家设置的 Position、Depth、Role 和 Outlet 不由镜渊覆盖。

## 安装

将安装 ZIP 作为 SillyTavern 第三方扩展安装。最低客户端版本为 SillyTavern 1.18.0。

面板包含四页：

- **运行**：完整处理、仅审核、仅提取、取消任务和四阶段实时状态。
- **世界书**：条目管理、召回映射和世界基础设定导入。
- **设置**：自动化开关、审核规则、阈值和 Connection Profile 路由。
- **维护**：自动验收、诊断、世界书重建和重置。

## 模型连接

### 一键统一

“镜渊处理连接”下拉框可将同一个 ST Connection Profile 分配给全部阶段。

### 分阶段映射

展开“按阶段分别选择（高级）”，可分别设置：

1. 审核；
2. 修正；
3. 提取与设定导入；
4. 小总结；
5. 大总结；
6. 世界书重建。

这允许正文使用网站 A / 模型 A，而镜渊不同阶段使用网站 B 或同一网站的其他模型。所有连接仍在 SillyTavern 的 Connection Profiles 中建立和测试。

未选择 Profile 的阶段跟随当前 SillyTavern 连接。

## 主模型切换规则

任务快照现在只关注该任务实际使用的路由：

- 当前任务所需阶段全部使用独立 Profile：切换主聊天模型不会取消任务。
- 任一所需阶段跟随当前连接：切换主连接或主模型会使旧任务作废，防止同一任务前后使用不同模型配置。
- 修改无关阶段 Profile 不影响当前任务。
- 修改当前任务会使用的 Profile 会使旧任务作废。
- 世界书提交和撤销等纯维护事务不受模型切换影响。

## 请求边界

选择 Profile 时，镜渊调用 ST 原生 `ConnectionManagerRequestService.sendRequest`；未选择时调用 `generateRaw()`。

每个业务阶段只提交一次请求。镜渊不自动执行：

- 网关或网络重试；
- HTML 错页兼容；
- 空正文重试；
- reasoning-only 救援；
- 缩短提示词后重放；
- 第二次模型格式修复。

失败会停止本阶段，不提交世界书，不推进处理游标，并显示 ST 返回的错误。

## UI 行为

- 常用玩家路径仍是一键统一 Profile。
- 高级映射只在展开后显示，不增加日常操作负担。
- 保存连接映射期间，七个下拉框统一临时锁定，防止快速切换造成竞态。
- 保存失败时恢复原选择，并立即显示错误。
- 状态通过面板与最新 AI 消息下方指示器同步显示。
- 移动端面板适配 390 px 宽度，主要操作按钮保持至少 44 px 触控高度。

## 本轮删除的冗余

- 无调用的提取格式修复模型阶段及提示词；
- 已停用的迁移限流自动重试常量和辅助函数；
- 恒为零的重试状态转发；
- 恒定活动包变化标记；
- 无调用辅助函数；
- 请求控制器中转对象；
- 未使用的批次参数。

旧活动包的确定性清理仍保留，但不会生成新的活动包。

## 保持不变

- 世界书正文和栏目格式；
- ENTRY 协议；
- 审核、提取、总结和重建的业务定义；
- 本地解析与安全恢复；
- 匹配、去重、生命周期和事件沉降；
- ST 原生召回参数；
- 玩家拥有的 Position、Depth、Role 和 Outlet。
