# Mirror Abyss 2.0.0-lite.ui.5

面向 SillyTavern 1.18 的轻量审核与固定格式世界书提取版。

## 面板

- 入口固定在右上侧、官方顶栏下方，不进入角色卡按钮容器。
- 加载占位按钮、启动按钮和真实面板按钮使用不同 DOM ID，主体启动后会清理占位按钮。
- 面板只保留“审核”和“提取”两个执行按钮。
- 五个独立开关：总开关、自动审核、自动提取、审核功能、提取功能。

## 异步队列

- 手动审核、手动提取和自动任务进入同一聊天的后台异步队列。
- 同一聊天严格串行执行，避免审核、正文替换和世界书写入并发冲突。
- 重复的同类型、同正文任务不会重复入队。
- 新正文到达时，旧正文任务会取消，最新正文进入队列。
- 自动审核和自动提取完全独立；两者同时开启时按“审核→必要时替换→提取”执行。

## 审核

- 审核通过：正文不修改，状态显示“审核通过，正文未修改”。
- 审核不通过：生成完整修正版，替换消息正文和当前 swipe，清除过期 `display_text`，保存聊天并回读校验。
- 提取在审核之后执行时，读取修正后的正文，不读取旧正文。

## 提取

- 一次模型调用输出固定 `ENTRY / KEYWORDS / CONTENT / END_ENTRY` 语法。
- 标题、关键词、正文分别写入世界书对应字段。
- 类型、稳定名称、关键词数量、关键词首项、小标题顺序、标记外残留文字均做严格校验。
- 同一事实只能归属一个条目；跨条目完全重复或去掉状态槽后仍重复时，整批拒绝写入。
- 事件过程只归事件，关系变化只归关系，其他对象使用关联条目引用。
- 当前状态按状态槽替换；经历和变化记录追加；“无”不清空旧事实；本地语义相似度用于旧事实去重。

## 状态灯

最新 AI 正文下方显示：

- 审核：排队、处理中、通过、已替换或失败。
- 提取：排队、处理中、提取到的条目标题、新建条目、更新条目、跳过条目或失败。

长内容可通过状态灯的标题提示查看完整条目列表。
