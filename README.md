# Mirror Abyss / 镜渊

SillyTavern 世界书整理扩展。世界书是当前正文事实的唯一权威来源；插件只保存 UID 归属、运行状态与回滚所需历史前态，不保存第二份当前正文。

## 当前主链

```text
AI 正文完成
→ 读取上一轮实际写入 UID
→ 从当前世界书 UID 索引取得这些 UID 的最新完整条目
→ 连同玩家本轮回复和当前 AI 正文交给提取模型
→ UID 命中即更新原条目
→ 否则只按稳定标题精确/规范化完整标题匹配原 UID
→ 标题未命中则创建新 UID
→ 不做身份冲突、事件生命周期、场景相似或别名语义消歧
→ 写入世界书
→ 本轮实际写入 UID 进入当前场景组
```

## 场景组与总结

```text
当前场景组
→ 只保存本场景实际参与的 UID
→ 地点不变继续累计
→ 换场后关闭整个场景组
→ 组内 UID 从当前世界书索引取得最新正文
→ 小总结
→ 当前结果标记 S
→ 完成的小总结场景组进入当前大组集
```

小总结负责整理一个场景已经形成、并会继续影响后续的局部有效结果；不以减少字数为目标，不强行拔高成世界整体规律。

```text
若干 S 小总结场景组
→ 达到自动阈值，或玩家手动“立即大总结”
→ 收拢当前大组集
→ 结合现有基础设定执行大总结
→ 提炼更基础、更整体、更稳定的世界运行规律
→ 正式产物只创建/更新基础设定
→ 来源 S → L
```

大总结不自动读取基石锁。基石锁由玩家手动设置和解除。

## UID 与 S/L

- UID 身份稳定，模型看不到真实 UID。
- 模型只看到本次请求使用的临时 `条目N`。
- `S` 表示 UID 当前状态已经完成小总结。
- `L` 表示 UID 当前状态已经完成大总结。
- 正常剧情再次更新已有 UID 时，旧 S/L 被清除；新状态重新参与后续总结。
- 场景组和大组集只保存 UID，不保存当前正文副本。

## 回合 UID 回滚

每个真实剧情回合只保存该回合实际修改 UID 的历史前态：

```text
UID
+ 对应回合
+ 写入顺序
+ 本回合第一次修改前的完整原文
```

Edit / Swipe / Delete：

```text
取消并清空当前聊天全部任务
→ 冻结新任务
→ 根据消息变化确定回滚边界
→ 按 UID 回合历史倒序恢复世界书原文
→ 删除已经失效的 UID 历史
→ 一次性提交新的运行元数据
→ 重新开放任务
```

场景组不参与恢复。恢复依据始终是 UID 回滚快照里的历史完整原文。

## 一次性运行基线

每个聊天第一次进入当前运行结构时只执行一次：

```text
扫描当前世界书实际 UID
→ 这些 UID 作为已有世界事实基线
→ 读取当前聊天最后一个明确地点
→ 以该地点创建空的当前场景组
→ 不把旧 UID 塞进场景组
→ 不推断旧 S/L
→ 写入一次性迁移完成标记
```

同一聊天之后启动、重开或切回都直接继续现有状态，不重复初始化。

整本世界书重建是独立的玩家显式操作；提交成功后，以重建后的世界书重新建立运行基线，不重新触发升级迁移。

## 每轮更新提示

最近一个已经完整处理完成的剧情回合中，真正发生世界书变化且当前仍存在的条目，在世界书 UI 对应条目上只显示：

```text
更新
```

不显示 UID、条数、原因或额外说明；下一完整回合会按该回合真实变化重新计算，不沿用更早回合的标记。

## SillyTavern 召回规划

召回规划负责宿主 World Info 的原生触发字段，不负责提取模型上下文。

- 当前场景：高权重/常驻。
- 上一场景：关键词召回。
- 更早场景：向量召回。
- 人物、物品、事件、世界等按各自规则设置关键词、向量、递归、深度和顺序。
- 基础设定作为长期稳定世界运行逻辑参与宿主召回。

## 整本世界书重建

重建不是压缩。

```text
整本世界书
→ 检查信息归属与颗粒度
→ 合并重复或过碎信息
→ 必要时拆分混合主体
→ 将附属信息收回正确宿主
→ 将具体过程整理为仍会长期影响后续的结果
→ 材料自然支持时才向更高层规律整理
→ 生成预览
→ 玩家确认后提交
```

重建不以减少条目或字数为目标，并尊重基石锁。

## 保存原则

- 世界书保存后进行一次权威回读。
- 业务写入的硬验证只确认创建/更新/删除结果、稳定标题和正文是否正确；召回投影字段不会反过来否决已经正确写入的业务事实。
- 正常提取只执行模型明确形成的操作，不再额外扫描整本世界书并自行删除“看起来为空”的旧条目。
- 回滚后台事务保留必要的 SillyTavern World Info 列表同步，但不强制重载世界书编辑器 DOM。
- 单次写入 receipt 只负责“刚写成功后任务立即失败”的本次事务撤销；回合 UID 快照负责玩家 Edit / Swipe / Delete 的历史回滚。

## 当前结构清洗状态

部署包只保留当前运行架构需要的模块与状态。已经退出主链的旧总结生命周期字段、旧总结容器分支、部署测试导出和零调用 helper 已移除；场景组/大组集只保存 UID，模型请求前临时从当前世界书建立 UID 索引读取正文。
