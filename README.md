# Mirror Abyss｜镜渊 2.0.0-alpha.9-infopoint.7-white-mobile

本候选的内核保持为：

```text
本轮正文
→ AI 提取标题、关键词、小标题和核心信息点
→ UID / 标题 / 别名 / 关键词 / 关联 / 少量正文匹配
→ 跳过、追加、同槽替换、事件链追加、创建或沉降
→ 直接写回 SillyTavern 世界书
```

世界书是唯一剧情数据源。UI 只读取、筛选、编辑并回读世界书投影，不保存第二套人物库、事件库、事实账本或图谱。

## 默认关键词与小标题

默认包含：时空、场景、人物、物品、事件、地点、全局变化、基础设定、能力、关系、组织、任务、契约、状态影响、资源和自定义对象。

旧设置缺少默认关键词、小标题或选项时，加载后会自动补齐；用户自定义关键词会保留。关键词页面另有“恢复完整默认项”按钮。

这些关键词不是白名单。宗教、法律、血统、货币、技术等新关键词仍可由模型或玩家创建。

含 `基础设定` 关键词的条目自动常驻并关闭向量调用；AI 不填写 constant、vector、recursion、depth 或 order。

## UI 调整

- 工作区改为白色主题。
- 功能开关固定在左上角：启用插件、自动处理正文、启用审核、自动创建世界书。
- 设置页不再重复显示这些开关。
- 移动端改为顶部开关区和横向标签栏。
- 信息表在手机宽度下转为逐条卡片，不再依赖 980px 横向表格。
- 按钮和输入控件使用触控友好的最小尺寸。

## 旧世界书格式转换

世界书页不再显示无效的“扫描并预览”。现在只有：

1. 转换旧世界书；
2. 撤销本次转换。

点击转换后，插件内部扫描当前世界书；没有需要转换的条目时不写入。存在旧格式条目时，确认后再转换。

转换保持原 UID 和 SillyTavern 原生字段。无法可靠识别的分类归入 `自定义对象`；无法可靠拆分的正文放入 `【旧格式保留】`，不猜造事实。
