# Mirror Abyss 2.0.0-lite.ui.1

面向 SillyTavern 1.18 的轻量操作版。

## UI

- 右上角“镜渊”入口，插入角色卡入口之前；找不到官方顶栏时使用右上角后备位置。
- 面板只保留“审核”“提取”两个按钮。
- 总开关、审核开关、提取开关相互独立。
- 最新 AI 正文下方显示审核与提取状态灯。

## 审核

点击“审核”读取最新一轮玩家输入与 AI 正文。通过时不修改；不通过时生成完整修正版并替换最新 AI 正文。

## 提取

点击“提取”后：

1. 一次模型调用输出人物、地点、物品、事件、关系五类固定格式条目。
2. 内置正则/结构解析器拆分标题、关键词和事实小标题，不依赖 SillyTavern Regex 扩展。
3. 标题写入世界书 comment，关键词写入 key，事实正文写入 content。
4. 已有条目按状态槽替换、经历链追加、关键词与关联条目集合合并。
5. 本地二元组语义相似度用于去除近义重复，不增加第二次模型调用。

## 默认行为

- 默认手动模式，不自动处理新消息。
- 默认使用当前连接。
- 当前聊天必须已绑定世界书。
- UI 只映射功能；审核、修正、提取、解析、合并与写入均由代码层执行。
