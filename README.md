# Mirror Abyss / 镜渊 3.0.0-lite.ui.1-exact-match

世界书是唯一长期事实源。模型负责语义整理，插件只负责批次、UID、保存、回读与回滚。

## 当前主链

```text
当前 AI 正文 + 玩家本轮回复 + 上一轮完整世界书
→ 提取细颗粒事实
→ 世界书

同一批世界书条目
→ 小总结：细 → 中
→ 返回什么就更新什么；本批未返回的旧条目删除

已完成小总结的条目
→ 大总结：中 → 粗
→ 同一完整条目整理协议
```

## 总结与人工整理

- UID 永远只在插件内部，模型看不到 UID。
- 模型只看到本次请求的临时 `条目1 / 条目2 / ...` 与完整正文。
- 原条目仍存在：返回原临时编号，系统保持原 UID 并整条更新。
- 真正形成新条目：模型返回 `新条目N`，系统创建新 UID。
- 本批原条目未被模型返回：系统删除其旧 UID。
- 小总结、大总结、选中总结、人工合并共用同一套完整条目整理方式。
- 总结协议没有空结果分支，也没有写回/移除/沉降、逐栏目 patch 或标题身份匹配。
- 人工合并与人工删除遇到基石锁时，先解除锁定再执行。

## 整本世界书整理

整本当前世界书一次交给模型，按大总结的长期颗粒度标准整理。先生成预览，确认后提交；失败保留旧书，提交后可撤销一次。

不再使用规划、分批、覆盖率、场景锚点、地区轮、规则轮等旧重建流程。

## 其他已收缩规则

- 审核只看当前 AI 正文。
- 正文修正只生成一次完整替换正文，不检查是否截断。
- 游戏时间不再保存独立聊天状态；设置后写成常驻 `基础设定｜游戏时间` 世界书条目，并随上一轮世界书一起进入提取。
- 不再执行离开场景时的额外世界书清理。
- 不再执行物品持有者/位置到人物或场景的隐藏同步。
- 玩家直接编辑世界书时不做额外语义治理，原 UID 保持不变。
- 重置只有“重置插件和世界书”：恢复默认设置、清除当前聊天镜渊状态并清空当前绑定世界书。
- 历史提示词兼容只保留紧邻上一个部署版本，不再背负更早版本的默认提示词迁移。

## 保存保护

世界书仍使用正式保存、保存后权威回读和失败回滚。玩家在世界书中的直接修改不会因为旧 digest 被镜渊拒绝。

## 回合 UID 回滚

- 不保存整本世界书历史快照。
- 每个真实剧情回合只保存“该回合实际改动过的 UID → 本回合第一次修改前的完整条目”。
- 同一回合内提取、小总结、大总结反复修改同一 UID，只保留最早前态。
- 只保留最近 20 个剧情回合；手动维护任务不占用剧情回合快照。
- Edit / Swipe / Delete 触发时，先等待受影响旧任务真正停止，再读取最终回合快照并回滚。
- 回滚只恢复受影响 UID；其他 UID 不动。
- 回滚不检查玩家后来是否又编辑过该 UID，也不因后来锁定/焦点而拒绝恢复；回合前快照直接覆盖该 UID。
- 如果某 UID 是该回合新建的，撤回该回合时直接删除该 UID。
- 世界书写入已经成功、随后任务才被打断时，会立即使用本次 UID 前态反向恢复，避免留下半次写入。
- 仅兼容紧邻上一个版本：旧 `commitReceipts` 会在读取时折算成回合 UID 快照。
