# Mirror Abyss 2.0.0-lite.ui.50-default-recall

本版基于 `2.0.0-lite.ui.49-scene-settlement`，只调整世界书召回配置与自动提取模式。

## 召回规则

- `基础设定` 是唯一常驻类型。
- 当前场景、上一场景、人物、物品、活动事件、世界状态均为关键词触发。
- 远期场景、历史事件、小总结和大总结使用向量触发。
- 焦点人物不再因焦点身份自动常驻，仍由人物名称和别名触发。
- 所有非基础设定条目回到 SillyTavern 新建世界书条目的默认落点：
  - Position：Before Char
  - Order：100
  - Depth：4（Position 不是 At Depth 时仅保留默认字段值）
- 触发条目阻止递归唤醒和继续递归，避免一条命中展开整本局部世界书。

## 自动提取模式

`自动提取` 开启后提供两个运行方式：

1. 默认：按场景结算
   - 首次识别场景字段只记录场景起点。
   - 完整场景字段相同，不调用提取模型。
   - 完整场景字段变化，旧场景执行一次提取和一次小总结。

2. 可选：每回合提取
   - 每条 AI 正文执行一次固定事实提取。
   - 小总结仍只在完整场景字段变化时生成。
   - 大总结仍按六个已结算场景触发。
   - 场景切换时只执行确定性的旧场景生命周期结算，不再次调用模型提取整个旧场景。
   - 没有场景字段的正文仍可逐轮提取，但不参与场景计数。

## 保持不变

- 自动审核仍可逐轮运行。
- 手动审核、手动提取、小总结、大总结继续可用。
- 场景字段仍按标准化后的完整字段值比较，不增加语义相似度。
- 不增加 Token 阈值、第二剧情数据库或复杂注意力状态机。
