# Mirror Abyss｜镜渊 2.0.0-alpha.9-infopoint.10-ui-status

Mirror Abyss 是 SillyTavern 世界书信息点提取与匹配扩展。世界书仍是唯一剧情事实源，UI 只做读取、编辑和回读映射。

## 本版 UI 调整

- 工作区退出按钮固定在整个工作区顶栏右侧；
- 酒馆页面入口固定显示在右上角，并使用内嵌 SVG；
- 删除重复的“世界书”页面，旧格式转换移入设置页；
- 总览只显示条目名称、关键词和一句当前摘要，不再放默认规则跳转；
- 信息表固定为“条目名称 / 关键词 / 子条目信息 / 状态与操作”，不再混列；
- 建议小标题改为紧凑标签，可单独添加或移除；
- 关系网络以焦点或连接最多的条目为中心，并按关键词分组；
- 设置页新增 SillyTavern 当前连接 / Connection Profile 选择，不要求填写 API Key；
- “AI 建议提取”先生成候选信息点，玩家确认后才写入世界书。

## 正文下方处理指示灯

每次处理会在目标 AI 正文正下方显示实时状态：

- 读取中；
- 审核中；
- 提取中；
- 匹配中；
- 写入中；
- 总结中；
- 待确认；
- 已完成；
- 处理失败。

指示灯只映射 TaskRunner 的真实状态，不保存第二套剧情数据。

## 子条目整理

默认建议小标题已缩减并统一。旧的“身份定义、对象定义、规则定义、能力定义”等会归一为“固定事实”；关系状态归入“当前状态”；历史事实和关系变化归入“变化记录”，减少同一条目中的重复栏目。
