# Mirror Abyss 2.0.0-lite.ui.9

面向 SillyTavern 1.18 的轻量审核、事实提取、总结沉降与世界书语义调度扩展。

本版只吸收参考包中经过验证的业务概念：事实归属、状态槽更新、事件关闭、总结分发、生命周期和召回重排。没有引入第二数据库、Runtime、Outbox、事务模拟、Reconciler 或大型状态机。

## 处理顺序

自动流程固定为：

1. AI 正文完成后进入当前聊天的异步队列。
2. 自动审核开启时先审核；失败时替换正文、保存并回读确认。
3. 自动审核关闭时完全跳过审核请求。
4. 自动提取开启时提取最终正文；审核替换过则读取修正版。
5. 根据回合数、关键变化量和队列压力决定是否执行小总结或大总结。

同一聊天串行执行，不同聊天互不覆盖。审核不会因为队列积压而被压缩；尚未开始的逐轮提取可以被一次总结任务替代。


## 审核正文替换与 504 控制

审核失败后的正文替换由 `HostAdapter.replaceAssistantText` 单点完成：同步 `message.mes`、当前 swipe，清除 `extra.display_text`，刷新消息、等待保存并回读校验。失败时恢复原正文，不再报告假成功。

模型请求不再统一使用同一输出预算。审核、修正、提取、格式修复和总结分别限额；只有 502/503/504、HTML 网关页、`No message generated` 等上游错误会使用精简提示词重试一次。业务格式错误、聊天切换和用户取消不会重试。

提取请求最多携带 6 个相关世界书条目，每个既有条目只携带压缩后的必要正文。旧 STscript 的请求较短但缺乏容错；当前代码保留容错，同时限制输入规模。详细审计见 `AUDIT_504.md`。

源码入口、关键函数、注释锚点和测试位置见 `CODE_INDEX.md`。

## 轻量语义匹配

模型只输出候选事实，代码负责：

- 匹配稳定对象；
- 决定事实的主要宿主；
- 当前状态按字段槽替换；
- 经历、变化和事件进程去重追加；
- 固定事实变化时保留历史；
- 同标题条目合并；
- 跨条目重复事实只保留直接归属版本；
- 生成确定性世界书操作。

世界书仍是唯一长期数据源。

## 提取容错

严格语法仍是：

```text
<<<ENTRY:类型:稳定名称>>>
<<<KEYWORDS>>>
- 稳定名称
- 关键词
<<<CONTENT>>>
【固定小标题】
- 完整事实句
<<<END_ENTRY>>>
```

允许类型：人物、地点、场景、物品、事件、关系。

插件会先本地处理代码围栏、解释文字、全角标记、重复控制标记、缺失结束标记、重复标题和重复小标题。有效条目会部分提交，异常片段单独隔离。只有一个安全条目都无法恢复时，才追加一次格式修复模型调用。

## 生命周期元数据

镜渊管理条目会在原世界书扩展字段中记录：

- `lifecycle`：core、active、recent、long-term、closed、historical 等；
- `semanticRole`：基础设定、焦点、场景容器、事件容器、总结容器或普通对象；
- `evidence`：确认、转述、存疑事实数量；
- `recallProfile`：当前采用的 SillyTavern 召回配置；
- `chatKey`：所属聊天。

这些只是世界书条目的轻量元数据，不构成第二剧情数据库。

## 事件关闭

只有正文或总结明确给出结束、完成、关闭或有效最终结果时，事件才被判断为关闭。人物暂时离场、长时间未出现或推测性语句不会自动关闭事件。

关闭后的事件：

- 不再成为递归桥；
- 转为向量历史条目；
- 禁止被递归链带出；
- 进入较深位置和较低顺序。

## 小总结和大总结

小总结由以下任一条件触发：

- 达到设置的回合数，默认 10；
- 累计达到关键变化阈值，默认 6；
- 异步队列积压需要压缩。

小总结更新 `总结｜当前事件`，并把人物、场景、物品、事件和关系事实分发回对应条目。关键变化按世界书确定性操作计算，不依赖模型直接决定触发。

大总结在有效小总结达到设置次数后触发，默认 5 次。它更新 `总结｜世界历史`，分发长期事实，并消费未锁定、非焦点的当前事件总结容器。

总结格式出现标题别名、重复总结块、缺失标准标题或附带额外块时，先做本地恢复和合并；不能安全恢复时才失败，不影响此前已经成功的审核和提取。

## 召回调度

每次写入或总结沉降后，插件根据条目语义确定原生世界书字段：

- 基础设定：常驻、递归隔离、角色定义前；
- 玩家焦点：常驻，但强制递归隔离；
- 最新场景或时空：最多一条递归桥，深度 4；
- 当前未结束事件：最多一条递归桥，深度 4；
- 普通和近期对象：关键词＋向量，递归终点；
- 长期人物、关系、能力、契约：角色定义后，递归终点；
- 小总结：对话深度 6，递归终点；
- 大总结、关闭事件和历史条目：对话深度 8，递归隔离。

## UI

右上侧独立入口。面板保留审核、提取、独立自动开关、总结阈值和只读“世界书语义与召回状态”。只读区域回读真实世界书，显示：

- 生命周期；
- 确认、转述、存疑事实数量；
- 常驻、关键词、向量；
- 递归桥、递归终点、递归隔离；
- 角色定义前、角色定义后或对话深度；
- Depth、Order、Scan Depth。

审核和提取均由插件 JavaScript 调用 SillyTavern `generateRaw`，不再执行旧 STscript。

## 实机边界

本地测试不能代替目标云端 SillyTavern、真实模型连接、移动端主题和世界书权限。安装后重点观察事件关闭判断、关键变化触发频率、总结格式恢复和世界书原生字段变化。
